## 2. 目标结构

```text
autowsgr/application/ui/controller/home/main_page/
├── __init__.py        # 导出 HomePage、HomeTarget 与红点识别
├── page.py            # HomePage：五个单击入口 + 导航目标枚举
├── constants.py       # 导航落点、浮窗点击坐标、通知探针与颜色
└── recognition.py     # 红点识别（保留在控制器）
```

## 3. 公开面（草案）

| 入口 | 语义 | 落点来源 |
| --- | --- | --- |
| `go_to(target)` | 点击目标页入口（出征 / 任务 / 侧边栏 / 后院 / 活动） | `constants.NAV_POSITIONS` |
| `click_news_checkbox(position)` | 勾选每日公告勾选框 | checker 识别产出的中心 |
| `click_news_close()` | 关闭每日公告 | `constants.DISMISS_POSITIONS` |
| `click_reward_claim(position)` | 点击每日奖励领取按钮 | checker 识别产出的中心 |
| `click_reward_confirm(position)` | 点击奖励确认按钮 | checker 识别产出的中心 |

- 与 event page 一致：**只做单次点击**，不等待、不重试、不 import checker；
- 首页是顶层页面，没有"返回上一级"，因此**不提供 `go_back`**。

## 4. 死代码清单（本批删除）

| 死代码 | 原因 |
| --- | --- |
| `workflow.py`（整文件） | 浮窗子流程与终态确认归导航器 |
| `page.py` 的 `dismiss_current_overlay` | 浮窗主流程归导航器 |
| `HomeOverlayError` | 只有浮窗流程使用 |
| `operations.py`（整文件） | 5 个点击并入 `page.py`，不再需要独立文件 |
| `page.py` 的流程参数（`_OVERLAY_CLEAN_DELAY_SECONDS` 等 3 个） | 流程参数随流程走 |
| `page.py` 对 `navigation.interaction` / `navigation.types.PageMatch` 的依赖 | 模块已不存在 |
| `page.py` 的 `navigate_to` 旧实现（含 `click_and_wait_for_page`） | 由 `go_to` 取代，等待归导航器 |

保留：`Target`（可能改名 `HomeTarget`）、`_TARGET_PAGES`、`NAV_POSITIONS`、`DISMISS_POSITIONS`、
`PROBE_POSITIONS`、`NOTIFICATION_RED`、`recognition.py`。

## 6. 已确认（沿用 event page 的结论）

| # | 结论 |
| --- | --- |
| 1 | 控制器只持有页面控制；识别归 checker |
| 2 | 控制器只做单次点击，前后识别由导航器控制 |
