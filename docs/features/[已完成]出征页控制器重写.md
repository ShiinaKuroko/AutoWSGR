## 0. 本批目标

重写 `autowsgr/application/ui/controller/operations/sortie_page/main_page`（出征页页面壳控制器）。
出征页是综合页面，靠顶部 tab 条切换业务（出征 / 演习 / 远征 / 战役 / 决战）。

控制器只保留**两个导航单击**与**远征红点探针**：

- `go_to`：点击目标 tab；
- `go_back`：点击返回，离开出征页；
- 远征红点探针：控制器自己用得到的状态判断，保留。

**tab 识别归 `sortie_checker`**（五个 `check_*_page` 已具备），**切 tab 的等待与确认归导航器**。

## 3. 公开面（草案）

| 入口 | 语义 | 落点来源 |
| --- | --- | --- |
| `go_to(tab, position=None)` | 点击目标 tab | `position`（checker 识别中心）优先，缺省用 `TAB_POSITIONS` 兜底 |
| `go_back()` | 点击返回，离开出征页 | `CLICK_BACK` |
| `check_expedition_notification(screen)` | 远征完成红点判定 | 控制器自用，保留 |

与前面两个控制器一致：**只做单次点击**，点击直接调 `ctx.runtime.ctrl.click`（不包 `_click`），
不 import checker、不等待、不重试、不判断结果。
