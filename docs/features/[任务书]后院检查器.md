## 4. 导航边（14 条）

```text
主页面 → 后院主页        点主页「进后院」；到达确认 = 四个入口任一（8 次 / 1 秒）
后院主页 → 餐厅          点餐厅入口中心（静态兜底）；到达 = 餐厅二级页
后院主页 → 学院          同上
后院主页 → 军阶室        同上
后院主页 → 浴室          同上
后院主页 → 主页面        点「退回」(0.0527, 0.0694)；经每日浮窗链，confirm=False
餐厅 → 主页面            点「通用回首页」(0.1305, 0.0708)；经浮窗链，confirm=False
学院 → 主页面            同上
军阶室 → 主页面          同上
浴室 → 主页面            同上
餐厅 → 后院主页          点「退回」(0.0527, 0.0694)
学院 → 后院主页          同上
军阶室 → 后院主页        同上
浴室 → 后院主页          同上
```

**离开确认无需特殊处理**：进了二级页，后院主页整个被换掉，四个入口一起消失，
所以 `check_backyard_page(absent=True)`（四个入口全不在）自然成立。

**二级页 → 后院主页的边要留着**（用户 2026-10-13 追加）：
用户场景是「从军阶室突然想去浴场」，算路会走 `军阶室 → 后院主页 → 浴场`。

**二级页上有两个回去的按钮**：退回上一级 `(0.0527, 0.0694)` 与直接回主页
`(0.1305, 0.0708)`；**后院主页回主页用的也是退回那个按钮**，与二级页退回上一级同位置。

## 5. 两处实现选择

**① 不用 sleep 3，改用拉长 checker 重试。**
用户说明：进后院有动画缓冲，但也可以不 sleep，改为拉长 backyard checker 的识别时间与次数。
本方案取后者：到达确认 **8 次 × 1 秒**（等效 8 秒缓冲，比 sleep 3 更稳），
且不必为「只有进后院才需要」的等待给执行器加通用参数。

**② 二级页的到达与离开用不同模板。**
到达用「二级页身份模板」（如餐厅二级页），离开用「进去时那个入口的模板」（如餐厅入口）——
用户明确要求「识别不到进入的入口模板」即视为离开。
