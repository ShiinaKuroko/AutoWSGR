## 2. 选船模块结论

`battle_preparation/fleet_change/` 当前不下沉到 `common`。

原因：

- `_selection.py` 直接打开并等待 `ChooseShipPage`，执行槽位点击和页面回退。
- `_detect.py` 读取准备页截图、`ctx.ocr` 和页面专用坐标，并依赖 OCR 文本匹配。
- `campaign.py`、`decisive.py` 和 `_change.py` 同时承载战役/决战差异和编队编排。
- 普通出征、战役、演习、活动、决战、业务测试和工具均直接消费该子包。

因此它不是无页面语义的通用规则库。纯规则子集未来可以在单独专题中评估是否下沉
到业务层，但当前保留在 UI 原目录，避免破坏用户重点维护的选船行为。
