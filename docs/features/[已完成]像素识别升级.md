它们等各自重写时再迁。

## 1. 升级后的形态

数据（`constants.py`）用新栈的像素规则模型：

```python
EXPEDITION_NOTIF_SIGNATURE = PixelSignature(
    name='expedition_notification',
    rules=(PixelRule(x=0.4953, y=0.0213, color=Color(245, 88, 47), tolerance=40.0),),
)
```

识别（`recognition.py`）改用带截图与重试的公开入口：

```python
def check_expedition_notification(ctx: ContextHandle) -> bool:
    """判断出征页顶部是否显示远征完成通知。"""
    return expect_pixels(ctx, signature=constants.EXPEDITION_NOTIF_SIGNATURE, attempts=1).satisfied
```

## 2. 语义保持

- **单帧探测**：旧实现是"取一帧比一次色"，因此用 `attempts=1`，不引入等待；
- 探针位置、颜色、容差**原值保留**，只换承载方式（散装常量 → `PixelRule`）；
- 识别函数签名从 `(screen)` 改成 `(ctx)`：新入口自己截图，调用方不再传截图。
